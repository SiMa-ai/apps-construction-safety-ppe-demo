# Dashboard fonts

IBM Plex Sans, Latin subset, normal weights 400, 500, and 600.
Self-hosted WOFF2 files from `@fontsource/ibm-plex-sans@5.2.6`:
https://www.npmjs.com/package/@fontsource/ibm-plex-sans/v/5.2.6

Distributed under the SIL Open Font License; see OFL.txt.
The dashboard serves these files locally, without a runtime CDN dependency.
